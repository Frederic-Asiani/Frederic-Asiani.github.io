# Portfolio — Frederic-Asiani

Ce dépôt contient un site portfolio statique généré automatiquement par GitHub Copilot Chat Assistant.

Fichiers ajoutés:
- index.html — page principale du portfolio
- styles.css — styles
- .github/workflows/deploy.yml — workflow pour déployer sur gh-pages

Instructions pour publier:
1. Le dépôt est public : le site peut être publié via GitHub Pages.
2. Déployer : onglet Actions → "Deploy portfolio to GitHub Pages" → Run workflow (ou pousser sur main pour déclencher automatiquement). Le workflow crée la branche gh-pages.
3. Activer Pages : Settings → Pages → Source : Branch = gh-pages / Folder = root → Save. Le site sera accessible à https://frederic-asiani.github.io/Frederic-Asiani
4. Personnalisation :
   - Remplace `contact@exemple.com` dans index.html par ton email réel.
   - Ajoute `resume.pdf` à la racine pour activer le bouton de téléchargement du CV.
   - Mets à jour le lien LinkedIn.

Si tu veux que le site soit à la racine (https://frederic-asiani.github.io), renomme le dépôt en `Frederic-Asiani.github.io`.
