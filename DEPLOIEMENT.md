# Déploiement GitHub Pages

Compte : Frederic-Asiani
Dépôt existant : Frederic-Asiani.github.io

1. Ouvrir https://github.com/Frederic-Asiani/Frederic-Asiani.github.io
2. Sauvegarder l'ancien contenu avant remplacement.
3. Sur la branche main, remplacer index.html et README.md par les fichiers de cette archive (interface GitHub « Add file » ou édition des fichiers existants).
4. Dans Settings > Pages, vérifier la publication depuis la branche main, dossier /(root), ou le workflow GitHub Actions existant.
5. Vérifier l'adresse https://Frederic-Asiani.github.io dans un navigateur après la publication.

Note : README.md dans ce dépôt décrit le site. Pour afficher un README directement sur la page de profil GitHub, créer séparément un dépôt public nommé exactement Frederic-Asiani et y déposer ce README.md.
